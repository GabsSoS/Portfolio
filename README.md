## ✨ O que cada página tem

- **Layout responsivo** para celular, tablet e desktop.
- **SEO local:** título e descrição por página, dados estruturados (schema.org em JSON-LD), `sitemap.xml` e `robots.txt`.
- **Botões de WhatsApp** para o visitante chamar o negócio direto da página.
- **Animações ao rolar** a página (IntersectionObserver), desligadas para quem prefere menos movimento (`prefers-reduced-motion`).
- **Páginas legais:** política de privacidade e termos de uso.
- **Tema próprio** por segmento, sobre uma base comum de estilos e scripts.

## 🗂️ Estrutura

```
_shared/          estilos e scripts comuns a todas as páginas
<segmento>/
  index.html      a landing page
  style.css       estilos da página
  theme.css       cores e fontes do segmento
  politica-de-privacidade.html
  termos-de-uso.html
  sitemap.xml
  robots.txt
index.html        vitrine com todas as páginas
```
